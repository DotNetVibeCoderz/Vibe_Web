# SimpleBlog - Gravicode Engineering 🚀

SimpleBlog is a robust, lightweight, and stylish blog engine built specifically for the Gravicode Engineering Team using **Blazor Server** and **.NET**.

## 🌟 Features
- **Cute Brutalism Design**: Eye-catching UI with soft pastel colors and bold borders.
- **Dynamic Content**: Post management with categories, tags, and comments.
- **SQLite Support**: Ready to go with SQLite and EF Core, easily upgradable to SQL Server or Postgres.
- **Multi-Storage**: Supports Local File System, Azure Blob, and S3 (configured via `appsettings.json`).
- **Responsive**: Looks great on PC, Tablet, and Mobile.
- **Timeline View**: Social-media style timeline with likes and expandable comments.

## 🛠️ Tech Stack
- **Framework**: ASP.NET Core Blazor Server
- **UI Library**: MudBlazor + Custom Brutalism CSS
- **ORM**: Entity Framework Core
- **Database**: SQLite
- **Styling**: Google Fonts (Lexend), FontAwesome

## ⚙️ Configuration
Open `appsettings.json` to configure:
1. **Connection String**: Database location.
2. **StorageSettings**: Switch between `FileSystem`, `Azure`, or `S3`.
