# FormDezigner

[![Language](https://img.shields.io/badge/language-CSharp-blue.svg)](https://docs.microsoft.com/en-us/dotnet/csharp/)
[![Framework](https://img.shields.io/badge/framework-Blazor%20.NET%209-purple.svg)](https://dotnet.microsoft.com/en-us/apps/aspnet/web-apps/blazor)

**FormDezigner** is a powerful and flexible web-based form designer built with Blazor Server. It allows users to create, manage, and preview dynamic forms through both a visual designer and a code-based editor.

---

## 🇮🇩 Bahasa Indonesia

### Deskripsi
FormDezigner adalah aplikasi desainer formulir berbasis web yang dibangun menggunakan teknologi Blazor Server dan .NET 9. Aplikasi ini dirancang untuk memudahkan pembuatan formulir dinamis dengan antarmuka yang modern dan responsif.

### Fitur Utama
- **Visual Designer**: Rancang formulir secara visual dengan berbagai komponen input.
- **Code Mode (Monaco Editor)**: Integrasi dengan Monaco Editor untuk pengeditan tingkat lanjut dengan dukungan snippet (JS, C#, Python).
- **Manajemen Database**: Penyimpanan formulir dan manajemen versi menggunakan Entity Framework Core dan SQLite.
- **Antarmuka Modern**: Dibangun dengan MudBlazor untuk pengalaman pengguna yang mulus.
- **Sistem Versi**: Mendukung penyimpanan versi formulir yang berbeda (versioning).
- **Ekspor/Impor**: Mendukung ekspor struktur formulir ke format JSON.

### Teknologi yang Digunakan
- **Frontend/Backend**: Blazor Server (.NET 9)
- **UI Library**: MudBlazor
- **Code Editor**: BlazorMonaco
- **Database**: SQLite dengan Entity Framework Core

### Cara Menjalankan
1. Pastikan .NET 9 SDK sudah terinstal.
2. Clone repository ini.
3. Jalankan perintah `dotnet run` di folder root proyek.
4. Buka browser dan akses URL yang tertera (biasanya `http://localhost:5000`).

## 🇺🇸 English

### Description
FormDezigner is a web-based form designer application built using Blazor Server and .NET 9. This application is designed to simplify the creation of dynamic forms with a modern and responsive interface.

### Key Features
- **Visual Designer**: Design forms visually with various input components.
- **Code Mode (Monaco Editor)**: Integrated with Monaco Editor for advanced editing with snippet support (JS, C#, Python).
- **Database Management**: Form storage and version management using Entity Framework Core and SQLite.
- **Modern Interface**: Built with MudBlazor for a seamless user experience.
- **Versioning System**: Supports saving different versions of forms.
- **Export/Import**: Supports exporting form structures to JSON format.

### Tech Stack
- **Frontend/Backend**: Blazor Server (.NET 9)
- **UI Library**: MudBlazor
- **Code Editor**: BlazorMonaco
- **Database**: SQLite with Entity Framework Core

### How to Run
1. Ensure .NET 9 SDK is installed.
2. Clone this repository.
3. Run `dotnet run` command in the project root folder.
4. Open your browser and navigate to the displayed URL (usually `http://localhost:5000`).
